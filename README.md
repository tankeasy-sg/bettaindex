# Betta Index

A lightweight, single-page web app inspired by the structure and vibe of `jurassic.lovable.app`, adapted for cataloging wild *Betta* species with a dark, freshwater aesthetic.

## Run locally

Because this is a static site, you can open `index.html` directly in a browser, or serve it with a tiny local server:

```bash
python -m http.server 8080
```

Then open <http://localhost:8080>.

## Features

- Search by species/common name/region/water style.
- Filter chips by habitat type.
- Species cards with quick profile details.
- Modal profile view with expanded species information.
